How to open the report

  1. Download the Hospital_Patient_Dashboard.pbix file using the button above.
  2. Install or open Microsoft Power BI Desktop.
  3. Open the downloaded PBIX file and explore its report pages, filters and visual interactions.

This portfolio page hosts the downloadable report. GitHub Pages does not run a native PBIX file interactively in the browser.

Privacy and responsible use

Only publish this project publicly after verifying that the underlying report and data contain no real or identifiable patient information. Use synthetic or properly anonymized data. Do not upload private health information to a public repository.
